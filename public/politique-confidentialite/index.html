POLITIQUE DE CONFIDENTIALITÉ

1. RESPONSABLE DU TRAITEMENT

Finition Royale — contact@finitionroyale.fr — Besançon (25), France

2. DONNÉES COLLECTÉES

Nous collectons les données suivantes via le formulaire de prise de rendez-vous :

  • Prénom et nom
  • Numéro de téléphone
  • Adresse email (optionnel)
  • Type de véhicule et service souhaité
  • Commune d'intervention
  • Date et créneau souhaités

3. FINALITÉ DU TRAITEMENT

Ces données sont utilisées exclusivement pour :

  • Traiter votre demande de rendez-vous
  • Vous contacter pour confirmer le créneau
  • Vous envoyer une confirmation de réservation

4. BASE LÉGALE

Le traitement est fondé sur votre consentement explicite (case à cocher dans le formulaire) et sur l'exécution du contrat de prestation de service.

5. DURÉE DE CONSERVATION

Vos données sont conservées pendant 3 ans à compter du dernier contact. Elles sont ensuite supprimées définitivement.

6. DESTINATAIRES

Vos données ne sont jamais vendues ni partagées avec des tiers. Seul l'équipe Finition Royale y a accès pour traiter votre demande.

7. COOKIES

Ce site utilise :

  • Cookies analytiques (Google Analytics) : mesure d'audience, uniquement avec votre consentement. Ces données sont anonymisées (IP masquée).
  • Cookies de fonctionnement : mémorisation de vos préférences de consentement.

Aucun cookie publicitaire ou de ciblage n'est utilisé.

8. VOS DROITS

Conformément au RGPD, vous disposez des droits suivants :

  • Accès : obtenir une copie de vos données
  • Rectification : corriger des données inexactes
  • Suppression : demander l'effacement de vos données
  • Opposition : vous opposer au traitement
  • Portabilité : recevoir vos données dans un format structuré

Pour exercer ces droits, contactez-nous : contact@finitionroyale.fr

En cas de réclamation non résolue, vous pouvez contacter la CNIL : www.cnil.fr
